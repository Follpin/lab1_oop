Остапенка Романа К-24

Варіант 3 (1, 2, 3, 6):

  	*Бінарні операції: +, -, *, /
  
  	*Цілочисельні операції: mod (остача), div (ціла частина)
     
  	*Унарні операції: +, -
     
  	*Функції: max(x, y), min(x, y)
  
  	*Операнди: цілі числа, посилання на клітинки (пр: A1, B2), дужки ().

Підтримується 2 режими відображення: ВИРАЗ та ЗНАЧЕННЯ.
Для перерахунку значень натисніть Порахувати.
